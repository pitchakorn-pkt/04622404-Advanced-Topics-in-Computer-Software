# LAB02 — ปัญหาของระบบค้นคืนนี้ และสิ่งที่ทำได้

[English](README.md) · ภาษาไทย

ปัญหาหกข้อที่พบในระบบถาม-ตอบคู่มืออาหารไทยใน [`../`](../)
แต่ละข้อเขียนไว้ว่าเกิดอะไรขึ้น เพราะอะไร ตรวจสอบยังไง และการแก้จะมีราคาเท่าไหร่

หมายเหตุเรื่องที่มาของโค้ด — โค้ดใน `src/` และ `labs/` เป็นโครงต้นฉบับของแล็บที่ไม่ได้แก้
สิ่งที่แล็บนี้ทำคือคลังอาหารไทย 90 คู่
สิ่งที่เขียนไว้ในนี้จึงเป็นปัญหาของระบบตามที่มันเป็น ไม่ใช่รายการสิ่งที่ทำพลาดระหว่างสร้าง
และหลายข้อเป็นค่าเริ่มต้นที่ติดมา ซึ่งคอมเมนต์ในโครงต้นฉบับเองปิดไว้

ตัวเลขทุกตัวในนี้วัดจากระบบนี้จริง แต่ละข้อมีสคริปต์ที่ทำซ้ำได้

## วิธีรัน

```bash
cd LAB02/problems
python main.py        # เมนู
python main.py 3      # ดูข้อเดียว
python main.py 0      # ทั้งหกข้อ
```

ข้อ 1 และ 3–5 ต้องโหลดโมเดล embedding เพราะการทำซ้ำต้องเข้ารหัสคำถามที่คลังไม่เคยเห็น
เป็นโมเดลตัวเดียวกับที่ `main.py` ใช้ โหลดครั้งเดียวแล้วใช้ร่วมกัน
ส่วนข้อ 2 และ 6 อ่านจากไฟล์ที่ commit ไว้อย่างเดียว

## สิ่งที่ร้อยหกข้อนี้เข้าด้วยกัน

ห้าในหกข้อเป็นของที่มีอยู่แต่ไม่ถูกใช้ หรือถูกตั้งค่าไว้แต่ไม่ทำงาน
ค่าขนาด chunk ไม่มีผล ชื่อเมนูไม่มีใครอ่าน `TOP_K` ถูกเขียนทับ
คะแนนที่ใช้ปฏิเสธได้ไม่เคยถูกเทียบกับอะไร และคำถามทดสอบไม่เคยถูกรัน
ระบบทำงานได้ และสิ่งที่สร้างไว้ให้มันส่วนใหญ่ไม่ได้มีส่วนร่วม

ข้อ 3 ต่างออกไป มันไม่ใช่ของที่ถูกปิดไว้ แต่เป็นข้อจำกัดของโครงสร้างที่เลือก
และไม่มีค่าตั้งไหนไปถึง
