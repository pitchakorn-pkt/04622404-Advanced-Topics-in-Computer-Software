# LAB06 — RAG Workflow Presentation

English · [ภาษาไทย](README.th.md)

An oral check on understanding rather than a coding lab, held on 19 August 2026.

Each student prepared one or two PowerPoint slides summarising the RAG workflow of the
system they had built themselves, then presented them 1:1 with the instructor. The slides
had to be a diagram of the sequence the real system follows — input, retrieval, context,
LLM, output — rather than paragraphs of text. During the session the student opened their
own GitHub repository and, for every step in that flow, named the file and the function
that carries it out and explained what it does.

The system I presented is the Thai retrieval-augmented Q&A system for everyday phone and
computer problems in [`LAB04/`](../LAB04/). Its workflow, the files behind each stage, and
the measured retrieval results are all in [`LAB04/README.md`](../LAB04/README.md).

There is no source code of its own in this folder — the work being assessed was the
explanation, and the code it refers to lives in `LAB04/`.
