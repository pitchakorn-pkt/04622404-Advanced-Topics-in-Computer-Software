# LAB06 — การนำเสนอ RAG Workflow

ภาษาไทย · [English](README.md)

สอบวัดความเข้าใจแบบพูด ไม่ใช่ใบงานที่ต้องเขียนโค้ด จัดขึ้นวันที่ 19 สิงหาคม 2569

นักศึกษาแต่ละคนทำสไลด์ PowerPoint 1–2 แผ่น สรุป RAG Workflow ของระบบที่ตัวเองพัฒนา
แล้วนำเสนอแบบ 1:1 กับอาจารย์ สไลด์ต้องเป็นไดอะแกรมของลำดับการทำงานจริงของระบบ —
input, retrieval, context, LLM, output — ไม่ใช่ย่อหน้าข้อความ ระหว่างนำเสนอต้องเปิด
GitHub ของตัวเองประกอบ และบอกให้ได้ทุกขั้นว่าเกี่ยวข้องกับไฟล์ใดและฟังก์ชันใด
พร้อมอธิบายว่าโค้ดส่วนนั้นทำหน้าที่อะไร

ระบบที่นำเสนอคือระบบถาม-ตอบภาษาไทยแบบ RAG เรื่องปัญหามือถือและคอมพิวเตอร์ใน
[`LAB04/`](../LAB04/) รายละเอียดของ workflow ไฟล์ที่รับผิดชอบแต่ละขั้น และผลการวัด
การค้นคืน อยู่ใน [`LAB04/README.th.md`](../LAB04/README.th.md)
