# ปัญหาข้อ 05 — การเรียกข้ามเครือข่ายที่ล้มเหลวโดยไม่บอกสาเหตุ

[English](problem05_http.md) · ภาษาไทย · ทำซ้ำ: `python main.py 5`

pipeline นี้เรียก HTTP ผ่าน `urllib` ล้วน ไม่เพิ่ม dependency ใด ๆ
เป็นการเลือกโดยตั้งใจ และมันมีราคาสามอย่าง สองอย่างแก้ไปแล้วในโค้ดปัจจุบัน อีกอย่างยังไม่แก้

## 1. Cloudflare ปฏิเสธ User-Agent ของ urllib — แก้แล้ว

`urllib` ประกาศตัวเองว่า `Python-urllib/3.x` ซึ่ง Cloudflare ปฏิเสธทันทีบาง endpoint
ตอบกลับเป็น HTTP 403 พร้อมข้อความ `error code: 1010` โดยที่คำขอยังไปไม่ถึง API ด้วยซ้ำ

สิ่งที่ทำให้หายาก — 403 อ่านเหมือน "key นี้ไม่มีสิทธิ์" ซึ่งเป็นสิ่งแรกที่ทุกคนจะไปไล่
ทั้งที่มันไม่เกี่ยวกับ key เลย และ Groq ตอบ 403 ไม่ใช่ 404 ทำให้ยิ่งดูเหมือนปัญหาสิทธิ์เข้าไปอีก

```
embedding.py:77    USER_AGENT = "Advance-AI-RAG/1.0"
embedding.py:409   headers = {"User-Agent": USER_AGENT, **headers}
```

แค่ประกาศชื่อผู้เรียกก็ผ่าน และเป็นสิ่งที่ HTTP client ตัวไหนก็ส่งไปอยู่แล้ว

## 2. ตัวลองใหม่ที่ทิ้งเนื้อความของคำตอบ — แก้แล้ว

`post_with_retry()` จับ `HTTPError` แล้วรายงานแค่รหัสสถานะ
ความล้มเหลวทุกแบบจึงหน้าตาเหมือนกันหมดจากข้างนอก
และข้อความที่บอกสาเหตุจริง — `error code: 1010` ในข้อ 1 — ถูกทิ้งไปพร้อมกัน

```
embedding.py:435   detail = error.read().decode("utf-8", "replace").strip()[:400]
embedding.py:84    RETRY_STATUS = frozenset({408, 409, 429, 500, 502, 503, 504})
```

429 อยู่ในชุดที่ลองใหม่ เพราะ Gemini free tier วัดโควตาเป็นโทเคนต่อนาที
และตอบ 429 ให้ทั้ง batch เมื่อหน้าต่างนั้นเต็ม เป็นความล้มเหลวชั่วคราวที่รอแล้วหาย
ส่วน 403 ไม่อยู่ในชุด เพราะรอไปก็ไม่หาย

การแก้ข้อนี้คือสิ่งที่ทำให้ข้อ 1 กับข้อ 3 หาเจอได้ในเวลาอันสั้น

## 3. ชื่อโมเดลที่ผู้ให้บริการถอดออก — ยังไม่แก้

```
vector_store.py:84   DEFAULT_LLM_MODEL = "llama-3.3-70b-versatile"
```

Groq ถอดโมเดลตัวนั้นออกไปแล้วเมื่อ 18 สิงหาคม 2026 — พบตอนทำ LAB04
ซึ่งใช้ผู้ให้บริการเดียวกัน และแก้ config ที่นั่นไปแล้ว

อาการคือคำขอถูกปฏิเสธเพราะชื่อโมเดล ไม่ใช่เพราะ key หรือโควตา
ซึ่งดูจากรหัสสถานะอย่างเดียวแยกไม่ออก การแก้ข้อ 2 คือสิ่งที่ทำให้แยกออก

โค้ดเตือนเรื่องนี้ไว้แล้วที่ `vector_store.py:74-76` ว่าให้เช็ครายชื่อโมเดลก่อนเปลี่ยน
แต่รายชื่อนั้นเปลี่ยนได้เองโดยที่โค้ดไม่รู้
ค่าคงที่ที่ชี้ไปยังของนอกระบบจึงหมดอายุได้เสมอ

## บทเรียนร่วม

ความล้มเหลวของการเรียกข้ามเครือข่ายมาถึงในรูปของตัวเลขสามหลัก ซึ่งบอกน้อยเกินกว่าจะไล่หาสาเหตุได้
สิ่งที่บอกได้คือเนื้อความที่มากับมัน การทิ้งเนื้อความนั้นแพงกว่าที่คิดเสมอ
