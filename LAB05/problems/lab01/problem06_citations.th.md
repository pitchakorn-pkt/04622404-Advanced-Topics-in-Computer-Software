# ปัญหาข้อ 06 — คำตอบที่อ้างอิงประกาศซึ่งไม่มีอยู่จริง

[English](problem06_citations.md) · ภาษาไทย · ทำซ้ำ: `python main.py 6`

## เงื่อนไขที่ระบบบังคับ

ทุกข้ออ้างในคำตอบต้องมีป้ายของข้อความที่มันมาจาก

```
[jobicy_software_en:147496#2]     แหล่ง : id ของประกาศ # ลำดับ chunk
```

รูปแบบเดียว `CITATION_PATTERN` (`vector_store.py:97-104`) ถูกใช้สองที่ —
เขียนลงคำสั่งที่ส่งให้โมเดล และใช้ตรวจสิ่งที่โมเดลเขียนกลับมา ทั้งสองจึงไม่มีทางหลุดจากกัน

## คำตอบสามแบบผ่านตัวตรวจจริง

ข้อความที่ส่งให้โมเดล

```
[aidevboard_ai:48720738-0f4b-483d-9739-14039ae457d0#0]
[jobicy_software_en:147496#2]
```

| คำตอบ | อ้างถูกต้อง | แต่งขึ้นเอง | ผล |
|---|---|---|---|
| อ้างอิงถูกต้อง | 2 | 0 | ผ่าน |
| UUID ผิดหนึ่งตัวอักษร | 1 | **1** | จับได้ |
| ไม่ใส่ป้ายเลย | 0 | 0 | ผ่าน |

ป้ายที่ถูกจับได้คือ `[aidevboard_ai:48720738-0f4b-483d-9739-14039ae457d1#0]` —
ตัวอักษรสุดท้ายของ UUID เป็น `1` ในขณะที่ประกาศจริงลงท้ายด้วย `0`

## ทำไมเคสที่สองถึงอันตรายที่สุด

คำตอบอ่านแล้วสมบูรณ์ ป้ายถูกรูปแบบ แหล่งถูก ลำดับ chunk ถูก
ผิดแค่ตัวอักษรสุดท้ายของ UUID ที่ยาว 36 ตัว

ไม่มีใครอ่าน UUID และไม่มีใครไล่ตรวจทีละตัว
ถ้าไม่มีการตรวจอัตโนมัติ คำตอบนั้นจะผ่านไปในฐานะคำตอบที่ดี โดยชี้ไปยังประกาศที่ไม่มีอยู่จริง
`answer()` รายงานมันเป็น `invented` (`vector_store.py:447`)
ซึ่งในโค้ดเขียนกำกับไว้ว่าเป็นความล้มเหลวแบบเดียวที่หน้าตาเหมือนคำตอบที่ดี

## ช่องที่ยังเปิดอยู่

เคสที่สาม — คำตอบที่ไม่ใส่ป้ายเลย — **ผ่าน**
การตรวจนี้ถามว่าป้ายที่เขียนมามีอยู่จริงไหม ไม่ได้ถามว่าทุกข้ออ้างมีป้ายกำกับครบหรือเปล่า
คำตอบที่ไม่อ้างอิงอะไรเลยจึงไม่ถูกจับ

## การตัดสินใจที่ตามมาจากเรื่องนี้

```
vector_store.py:79-84
# llama-3.1-8b was seen copying a UUID with one character wrong -- an answer
# that reads perfectly and cites a posting that does not exist. The invented
# check catches it, but a citation that has to be caught is not worth the speed.
DEFAULT_LLM_MODEL = "llama-3.3-70b-versatile"
```

`llama-3.1-8b-instant` ถูกจับได้ว่าทำแบบนี้จริงระหว่างทดสอบสี่คำถาม
ตัวตรวจจับมันได้ และข้อสรุปคือป้ายอ้างอิงที่ต้องคอยจับไม่คุ้มกับความเร็วที่ได้
ค่าเริ่มต้นจึงย้ายไปเป็นโมเดลใหญ่ และเก็บตัวเล็กไว้ให้เลือกด้วย `--model`

นี่คือกรณีที่การวัดผลเปลี่ยนการออกแบบ ไม่ใช่แค่รายงานตัวเลข

## วิธีตรวจสอบ

อ่านค่า `invented` ในผลลัพธ์ของ `answer()` ทุกครั้ง มันควรว่างเปล่า ทุกคำถาม ตลอดเวลา

ถ้าโมเดลไหนทำบ่อย ให้เปลี่ยนโมเดล ไม่ใช่ปรับ prompt —
ความสามารถในการคัดลอกสตริงยาวให้ตรงเป๊ะเป็นคุณสมบัติของตัวโมเดล ไม่ใช่ของคำสั่ง
