# ปัญหาข้อ 01 — กฎตัด boilerplate กินคุณสมบัติที่ผู้สมัครต้องมี

[English](problem01_boilerplate.md) · ภาษาไทย · ทำซ้ำ: `python main.py 1`

## กฎที่ใช้

`collect_boilerplate()` ตัดบรรทัดที่ปรากฏในเอกสารตั้งแต่ห้าฉบับขึ้นไป
โดยนับจำนวนเอกสาร ไม่ใช่นับจำนวนครั้ง ด้วยเหตุผลว่าบรรทัดที่ซ้ำกันข้ามประกาศที่ไม่เกี่ยวกัน
คือคำโฆษณาบริษัทหรือข้อความเรื่องโอกาสที่เท่าเทียม ไม่ใช่เนื้อหาของงาน
ส่วนบรรทัดที่ยาวไม่เกินสี่คำจะถูกเก็บไว้ เพราะมันคือหัวข้อ และขั้น chunking
ใช้มันเป็นขอบเขตในการแบ่ง (`cleaning.py:73-91`)

รันซ้ำบนผลจากขั้น Collection ที่ commit ไว้ ได้ `outputs/boilerplate_lines.json`
ออกมาตรงกันเป๊ะ — 77 บรรทัด เหมือนกันทุกบรรทัด

## จุดที่เหตุผลของกฎพัง

กฎนี้ถูกต้องก็ต่อเมื่อประกาศแต่ละฉบับเป็นอิสระต่อกัน ซึ่งคลังนี้ไม่ใช่

| นายจ้าง | ประกาศ |
|---|---|
| Canonical Ltd. | 36 |
| Nebius | 9 |
| Experian | 7 |
| iHerb | 5 |
| นายจ้าง 58 ราย | รายละ 1 |

นายจ้างรายเดียวคิดเป็น 36 จาก 160 ประกาศของ Jobicy
ประกาศของเขาย่อมซ้ำกันเองโดยธรรมชาติ บรรทัดของเขาจึงข้ามเกณฑ์ห้าเอกสารได้
โดยที่ไม่ใช่คำโฆษณาเลยแม้แต่น้อย

## ราคาที่จ่าย แยกตามนายจ้าง

สัดส่วนข้อความที่รอดจากกฎ boilerplate โดยเฉพาะ — ไม่รวมผลของการตัดแท็ก HTML
และการจัดช่องว่าง จึงเป็นการแยกดูเฉพาะกฎที่กำลังพูดถึง

| นายจ้าง | ประกาศ | ข้อความที่เหลือ |
|---|---|---|
| Canonical Ltd. | 36 | 67% |
| Nebius | 9 | 63% |
| Experian | 7 | 95% |
| iHerb | 5 | 41% |
| Welo Global | 5 | 100% |
| นายจ้าง 58 รายที่ลงประกาศเดียว | รายละ 1 | **100%** |

นายจ้างที่ลงประกาศเดียวไม่เสียข้อความให้กฎนี้เลยแม้แต่ตัวอักษรเดียว
ส่วน iHerb ที่ลงห้าฉบับเหลือข้อความ 41%
กฎนี้ลงโทษนายจ้างตามจำนวนงานที่เขาประกาศ ซึ่งไม่เกี่ยวอะไรกับว่าข้อความนั้นเป็นคำโฆษณาหรือไม่

> README ของแล็บนี้รายงานตัวเลข 86% / 86% / 59% / 34% สำหรับนายจ้างชุดเดียวกัน
> ตัวเลขชุดนั้นวัดเทียบกับความยาวดิบ *ที่รวมแท็ก HTML* ส่วนที่หายไปจากการตัดแท็ก
> ราว 14% จึงถูกนับเป็นการสูญเสียของทุกคน ทั้งสองชุดถูกต้อง —
> หน้านี้แยกดูเฉพาะกฎ ส่วน README รายงานการหดตัวทั้งหมด

## บรรทัดที่ไม่ใช่คำโฆษณา

สามบรรทัดจาก 77 บรรทัดที่ถูกเก็บ

```
Experience with Linux (Debian or Ubuntu preferred)
Experience with Microsoft Office Suite (Word, Excel, PowerPoint)
Bachelor's Degree in Computer Science or related field preferred
```

ทั้งสามคือคุณสมบัติที่ผู้สมัครต้องมี ถูกลบออกจากทุกประกาศที่ระบุไว้
ซึ่งกระทบถึงคำถามตัวอย่างใน README ของแล็บโดยตรง —
การค้นว่าใครรับสมัครงาน Kubernetes จะได้คำตอบจากประกาศที่ข้อความระบุว่าต้องใช้ Linux หายไปแล้ว

## วิธีตรวจสอบ

1. รัน `python main.py 1` แล้วอ่านคอลัมน์ "ข้อความที่เหลือ"
   ถ้ากระจายกว้างมากระหว่างนายจ้าง แปลว่ากฎกำลังลงโทษตามจำนวนประกาศ ไม่ใช่ตามเนื้อหา
2. อ่าน `outputs/boilerplate_lines.json` ด้วยตาทั้ง 77 บรรทัด
   ไฟล์นี้ถูกเขียนทุกครั้งที่รันขั้นทำความสะอาดก็เพื่อการนี้

## สิ่งที่จะแก้ได้

นับ **จำนวนนายจ้าง** ที่บรรทัดนั้นปรากฏ แทนจำนวนเอกสาร
คำโฆษณาที่หลายบริษัทใช้เหมือนกันจะยังถูกตัด ส่วนคุณสมบัติที่บริษัทเดียวเขียนซ้ำในประกาศของตัวเองจะรอด

ยังไม่ได้เปลี่ยน เพราะผลลัพธ์ที่ทำความสะอาดแล้วคือสิ่งที่ทุกขั้นถัดไปถูกสร้างและวัดผลบนมัน
การเปลี่ยนกฎแปลว่าต้องรันใหม่ทั้งสาย
